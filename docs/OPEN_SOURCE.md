# 开源协作与成果记录

KeyNest 源于网络空间安全课程作业，现整理为可运行、可阅读、可贡献的独立开源项目。MIT 许可证允许在保留许可声明的前提下使用、修改和再分发。

## 基础信息

- 项目名称：KeyNest 密钥巢 — 本地教学密码管理器
- 公开仓库：https://github.com/Star2Moon/keynest-password-manager
- 技术方向：网络安全工具、密码存储与 Web 应用安全实践
- 主要技术：Python、SQLite、JavaScript、scrypt、AES-GCM
- 发起人：杨皓嘉（Star2Moon）
- 许可：MIT
- 定位：课程实践与开源协作，不宣称生产级安全

公开仓库不包含学号、私人录音、真实保险库或学校内部文件。需要个人身份信息的活动表格应在指定非公开渠道填写。

## 建议的真实协作路线

维护者先将清晰、可复现的问题建成 Issue。参与者自行 Fork 后完成有实际价值的代码、测试或文档变更，创建 PR；维护者进行 Review，处理反馈后 Merge。每个人只记录自己的真实工作，不通过批量空提交、虚构账号或互相刷 Stars 制造指标。

可选协作方向包括：跨浏览器验收与无障碍、HTTP 边界测试、安装文档与错误提示、安全备份设计。任务应按参与者能力拆分，避免多人提交完全重复的改动。

## 持续维护

修改通过测试后合并，使用 CHANGELOG 记录真实变化。发现安全问题按 SECURITY.md 协调。涉及主密码修改、导出或迁移等风险较高的能力，先讨论设计和数据安全，再提交实现。
